# Marque 3.0 — 2026-08-13

## What changed

Every Marque package now requires **PHP 8.4** and **Laravel 13**. This was a
floor raise across the whole suite — one change, applied everywhere, so
every package bumped its major version together even though nothing else
about them changed.

## Who's affected

Everyone. If you run any Marque package, this applies to you.

## What you need to do

**If you already have any Marque package installed**, raise Laravel and every
Marque package you use in **one atomic `composer require`**, naming both the
Laravel bump and every package's target version together:

```bash
composer require laravel/framework:^13.0 laravel/tinker:^3.0 \
  marque/trove:^3.0 marque/threepio:^3.0 marque/bloodhound:^3.0 \
  marque/cennad:^3.0 marque/guise:^3.0 marque/usarrs:^3.0 marque/disguise:^3.0 \
  marque/hound:^3.0
```

(Only require the Marque packages you actually use, but include every one of
them in the same command as the Laravel bump.)

**Don't try to upgrade Laravel first, then Marque, as two separate steps** — this
was the original instruction here, and it does not work in practice. An already-
installed old Marque version has its own constraints (e.g. bloodhound v2.0.0's
`illuminate/redis ^12.0`) that conflict with Laravel 13 just as much as Laravel 13
is needed by the new Marque version. Composer's own conflict output when you hit
this doesn't clearly name Laravel as the blocker — if `composer require` produces a
wall of package-vs-package messages, that's this problem; the fix is the single
atomic command above, not chasing the individual conflicts it reports.

**The two-step path (upgrade Laravel first, then require Marque) only works for a
genuinely fresh install** — an app with no Marque packages installed yet has
nothing to conflict, so there's no ordering problem to hit.

No config changes, no renamed columns or classes, no migrations either way. This is
a platform-floor bump, not a behaviour change.

## Packages affected

trove, threepio, bloodhound, cennad, guise, usarrs, disguise, hound — all
bumped from their v2.x line to v3.0.0 for this reason alone.
