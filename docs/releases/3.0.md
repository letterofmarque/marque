# Marque 3.0 — 2026-08-13

## What changed

Every Marque package now requires **PHP 8.4** and **Laravel 13**. This was a
floor raise across the whole suite — one change, applied everywhere, so
every package bumped its major version together even though nothing else
about them changed.

## Who's affected

Everyone. If you run any Marque package, this applies to you.

## What you need to do

Check your app is on PHP 8.4+ and Laravel 13+ before upgrading. If it isn't,
upgrade your app first — Marque 3.0 won't install otherwise (Composer will
tell you why).

Once your app meets those floors:

```bash
composer require marque/trove:^3.0 marque/threepio:^3.0 marque/bloodhound:^3.0 \
  marque/cennad:^3.0 marque/guise:^3.0 marque/usarrs:^3.0 marque/disguise:^3.0 \
  marque/hound:^3.0
```

(Only require the packages you actually use.)

No config changes, no renamed columns or classes, no migrations. This is a
platform-floor bump, not a behaviour change — if your app already runs on
PHP 8.4 / Laravel 13, upgrading is routine.

## Packages affected

trove, threepio, bloodhound, cennad, guise, usarrs, disguise, hound — all
bumped from their v2.x line to v3.0.0 for this reason alone.
