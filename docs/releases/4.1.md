# Marque 4.1 — 2026-08-26

## What changed

The BitTorrent "passkey" — the private key in your announce URL that
identifies you to the tracker — has been renamed to **"announce key"**
everywhere in Marque: the database column, the URL, the profile page, the
code.

## Why

Laravel itself now has a first-class "Passkey" feature (WebAuthn login —
the same passwordless sign-in you might use for your bank or Google
account). Since every Marque site is a Laravel app, that feature is one
config change away from being available on any of them.

Having two unrelated things both called "passkey" in the same app — one a
tracker credential, one a login method — was a support headache waiting to
happen. Renaming the tracker one avoids that confusion before anyone's
actually turned on Laravel's login passkeys. "Announce key" is also the
more accurate name — BitTorrent users and other private-tracker software
already use it, so nothing is lost by moving off "passkey".

## Who's affected

Only sites using **`marque/bloodhound`** (the tracker) and/or
**`marque/usarrs`** (the profile page where users see/regenerate their key).
If you don't use either of those packages, this doesn't affect you.

## What you need to do

**Your users' existing keys keep working.** This is a rename, not a reset —
nobody needs a new key, and no announce URL a client already has stops
working.

1. Upgrade:
   ```bash
   composer require marque/bloodhound:^4.0 marque/usarrs:^5.0
   ```
2. Run the migration — it renames the database column in place:
   ```bash
   php artisan migrate
   ```
3. If you customised `config/usarrs.php`, rename two keys:
   `show_passkey` → `show_announce_key`, `allow_passkey_regen` →
   `allow_announce_key_regen`.
4. If you published and customised the profile page view or reference the
   old `PasskeyManagement` class/`passkey` column anywhere in your own code,
   see the full technical checklist:
   [Upgrading to Bloodhound v4.0 / Usarrs v5.0](../upgrade-guide-bloodhound-v4-usarrs-v5.md).

If you haven't customised any config or views, steps 1–2 are all you need.

## Packages affected

- `marque/bloodhound` — v3.0.0 → v4.0.0
- `marque/usarrs` — v4.0.0 → v5.0.0

Nothing else in the suite changed in this release.
